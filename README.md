# CortexDJ for Homebrew

The Homebrew cask for [CortexDJ](https://cortexdj.com/), the offline AI DJ that builds and mixes sets from your own music. The Mac version runs on Apple silicon with macOS 13 Ventura or later, and it is in beta.

## Install

```bash
brew install --cask nessebar/tap/cortexdj
```

CortexDJ updates itself in place when a new version is out, so you rarely need `brew upgrade`.

## Uninstall

```bash
brew uninstall --cask cortexdj
```

This removes the app and keeps your settings, licence and library in `~/CortexDJ`. Add `--zap` only if you want those deleted too.
